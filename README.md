# The Bionic Reader
## Genesys Slackathon Project 2026 🔥

---

A Chrome extension that will identify blocks of text in webpages and auto-apply the bionic reading technique to help readability.

***What is bionic reading?*** Bionic reading is a technique used by people with different reading difficulties/learning disabilities that helps guide
the reader by providing 'anchors' in the text. The first few letters of every word are in bold to direct the eye.
